## 🌟 Key Features

* **🎨 Cyberpunk Glassmorphism UI:**
  * Rich dark-gradient canvas with neon cyan (`#00f0ff`) glow accents.
  * Frosted glass panels (`backdrop-filter: blur()`), subtle borders, and smooth hover elevation effects.
  * Custom typography featuring **Outfit** for bold headings and **Inter** for clean readability.

* **🤖 Interactive AI FAQ Chatbot:**
  * Floating widget with subtle pulsing animation in the bottom-right corner.
  * Instant, client-side keyword-weighted QA engine answering common client questions about skills, pricing, turnaround times, revisions, and deliverables.
  * Typing indicator animations and clean responsive chat window.

* **🖼️ Portfolio Showcase & Lightbox:**
  * Grid showcase featuring recent design commissions, poster art (e.g. Porsche GT3 RS), esports logos, and web mockups.
  * Full-screen interactive image lightbox modal for examining high-resolution artwork.

* **⚡ Interactive Skills Modal:**
  * Clickable skill cards opening descriptive modals covering graphic design, photo manipulation, branding, video editing, and web development.

* **💳 Clear Pricing Tiers & Deals:**
  * Transparent service rates with Starter, Pro, and Elite tiers.
  * Highlighted **Video Bundle Deal** card with glowing accent borders.

* **⭐ Client Reviews & StaticForms Submission:**
  * Star ratings and verified client testimonials.
  * Interactive review submission and contact inquiry forms powered by **StaticForms** API.

* **🛡️ Asset & Content Protection:**
  * Guardrails against unintended text drag and image extraction (`user-select: none`, disabled image drag, and protected context menu).

## 💻 Running Locally

No complicated build systems, Node modules, or package managers are required.

### 1. Clone the repository
```bash
git clone https://github.com/KnightFuryXY/huzefa-portfolio.git
cd huzefa-portfolio
```

### 2. Launch the site
You can open `index.html` directly in your browser, or serve it using any lightweight local HTTP server:

**Using Python:**
```bash
python -m http.server 8080
```
Then visit `http://localhost:8080` in your browser.

**Using VS Code Live Server:**
* Right-click `index.html` and click **"Open with Live Server"**.

**Using Node.js:**
```bash
npx serve .
```
